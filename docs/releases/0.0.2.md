# Overseer 0.0.2

- 앱 내 업데이트 확인·다운로드·설치·재시작을 지원합니다.
- 첫 실행 준비와 로그인 시 백그라운드 실행 동작을 개선했습니다.
- 화면 라우팅, 인앱 타이틀바와 마우스 뒤로가기를 지원합니다.
- Docker Compose CLI 미설치 상태를 메뉴에 안내합니다.
- 이미지 저장소의 개요·태그 메뉴, 즐겨찾기와 상세 설명 패널을 추가했습니다.
- 익명 Docker 볼륨 표시를 정리했습니다.

Apple Silicon용 DMG입니다. 기존 0.0.1 사용자는 이번 DMG를 직접 설치하시면 다음 버전부터 앱 내 업데이트를 사용할 수 있습니다.
